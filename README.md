Project Title - The history of Reggae music.
Project Description - The project is a narrative story about Reggae music and show how music can have an impact, and I would say that this would fit in the browser so more people can read about Reggae music and see what the music means to everyone.
Interaction - The user will be able to click on buttons to move through the story, the user will be able to hover over an image to see the image from a closer perspective, and the user will be able to listen to audio while moving through the story which is a reggae tune.
Concept - My project will be exploring about creating a space for my audience, because I feel like the hypertext narrative part of my project builds a space in some sense, as the whole point is to create a story and with my project I will try to put my audience in a space, which would be Jamaica since that’s where Reggae came to be.
Tools - I used HTML / CSS / JavaScript / Images / Audio.
Credits - Images: I used images from google for my project and made sure they fit the scene for my project.
Audio: I looked up a reggae tune on YouTube and recorded the reggae tune as the audio for my project.
AI Use Note - I used google gemini as a reference to roughly have an idea how to organize my css and javascript.
